# ELYPROOF Whitepaper

## Vision and mission

**Vision.** A chain is only as legible as the tools that read it. ELYPROOF wants every holder, builder and curious visitor on Elysium to see what is moving, in plain numbers, without trusting a middleman.

**Mission.** Publish a fast, honest, open pool board for Elysium. Show source data as it arrives, show a dash when it does not, and never invent a figure.

## Principles

1. Source-true: figures come directly from open market feeds.
2. Quiet by default: no popups, no dark patterns.
3. Verifiable: every external fact has one record and one owner in the code.
